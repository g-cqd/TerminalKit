# Diary — 2026-10-19 (09)

## Roadmap 0009: input off the cooperative pool

Decision and numbers: ADR-0023.

| Claim | Probe | Verdict |
|---|---|---|
| A reading InputSource takes a pool thread | `InputPoolProbe`: ten CPU-bound tasks, alone and beside a source reading an idle PTY | **CONFIRMED**: 15.6 → 23.4 ms |
| A stopped source gives its thread back | the probe's first version, one source per trial, no byte ever sent | **REFUTED**: each trial slower (24, 36, 47, 60, 114 ms), the pool exhausted by the tenth, the probe hung |
| A dedicated thread restores the batch | the same probe after the change | **CONFIRMED**: 15.5 alone, 15.7 beside a source |
| Keystroke latency changes | a key written while twenty busy tasks fill the pool | **No change**: 0.02 ms both ways, with the consumer on the main thread |
