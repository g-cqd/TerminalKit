# 2026-11-10 (01): optional word wrapping keeps the editable source map (ask n57)

`InputLayout` previously hard-wrapped all input, including prose. ask's input used this map both to draw and navigate; changing
only painting would break click/selection offsets and Up/Down. The optional `wrapsWords` mode keeps those operations on one map.
No caller changes without opting in. Whitespace is preserved in source and display, not trimmed or turned into newlines.

## Evidence

- `swift test -c release --enable-testable-imports --filter WordInputLayoutTests` with the new mode disabled: 15 issues, including
  `hello world` rendered as `hello wo` / `rld`. An over-strong offset equality was corrected to cell equality: a hard newline at
  a full row can share its cell with the following source boundary, as in the existing layout tests.
- Re-enabled mode: `hello ` / `world`, and source offset 6 is row 1, column 0. Corrected one test's manually counted offset:
  offset 9 after `hi there\n` is column 0, not 1. No implementation was changed for that mistaken expectation.
- `Scripts/quality.sh --check`: passed, including release tests, strict format/metrics and the isolated signal-safety check.
  Existing hard-wrap equivalence tests remain green. Word tests cover small widths, tabs, newlines, controls, zero-width,
  combining characters and CJK source/cell mapping.

## Cost

`Scripts/measure-word-input.py` compiles the actual layout/width/sanitiser sources with `swiftc -O`. Nine interleaved pairs,
100 layouts per sample, shared machine. Same source and inputs for hard and word-aware modes; this is feature cost, not a speedup:

| Corpus | Hard layout median / range (us) | Word layout median / range (us) |
|---|---|---|
| ASCII prose, about 6.6 KB | 30.4 / 30.2–32.0 | 176.1 / 174.0–185.5 |
| CJK/combining/emoji, 100 lines | 199.7 / 193.3–209.1 | 281.1 / 274.2–313.1 |

The first word implementation scanned every ASCII character as a grapheme and cost median 526.8 us on the ASCII corpus.
Scanning ASCII words by bytes reduced that to 176.1 us; the optional mode still costs more than hard wrap. Existing map lookup
and viewport operations are unchanged. ask caches the layout while only the cursor moves. Real-terminal appearance is deferred.
