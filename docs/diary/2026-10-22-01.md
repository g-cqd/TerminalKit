# Diary — 2026-10-22 (1)

## A shared display-row map and bounded viewport for input

Roadmap 0019; ADR-0032. `InputLayout` maps source grapheme boundaries to wrapped cells and cells back to source offsets. `InputViewport`
keeps a cursor in a host-capped display-row window and exposes the number of clipped rows above and below. Neither chooses ask's policy.

### Problems caught

- The first queued test run never ran tests: Agora's child was under Rosetta (`arch` i386, Swift target x86_64), while the test helper
  was arm64. The produced bundle was x86_64 (`file` confirmed it). Running queued commands with `/usr/bin/arch -arm64` fixes the host
  mismatch; no package or compiler strictness flag was weakened. `job-250` then produced the real red failures.
- A local initializer function captured `self.columns`; Swift rejected passing an immutable stored property through that capture. A
  local immutable width avoids capturing the initializing value; the field remains `let`.
- The first hard-newline-at-edge policy clamped to the last cell. A full-row wide grapheme made that a continuation cell. The shared
  next-row caret fixes both the geometry and reverse mapping, and generated tests now check continuation cells independently.
