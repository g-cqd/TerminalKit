### Probes and actual exits

Added a dedicated test target with an explicit `TerminalKitCodecs` target dependency.
Its `@testable` import checks compilation; its ASCII decode assertion checks linking/behavior.

1. `swift test -c release --filter KeyboardDecoderTests`: exit 0.
2. `swift build --build-tests -c release`: exit 1, compatible-module error at the import.
3. `swift test -c release --enable-testable-imports --filter KeyboardDecoderTests -v`: exit 0.
   Codecs compiler invocation contains `-O -whole-module-optimization -enable-testing`.
4. Same enabled-test command with both original timing `unsafeFlags` restored: exit 0.
   Reverted those two experimental settings afterward.
5. `swift test -c release --disable-testable-imports --filter KeyboardDecoderTests`: exit 1,
   same compatible-module error. This is the negative control.
6. `swift test -c release --skip-build --filter KeyboardDecoderTests`, after enabled build: exit 0.

The failure was reproducible by switching commands, without touching library source. The previous
investigation conflated building tests with requesting testable library builds.
Raw logs during the investigation: `/tmp/tk-testability-{red,green,disabled,rerun}.log`,
`/tmp/tk-build-tests.log`, `/tmp/tk-unsafe-flags-control.log`. Those temporary files are not durable;
the permanent codec test, gate and ADR-0012 preserve the reproduction and decision.

### Decisions and next entry

- Gate builds/runs optimized tests with explicit testability, rather than first building an
  incompatible release test graph.
- Shipping/benchmark binaries use ordinary release builds: testability can affect visibility and
  optimization, so these builds are not claimed to be identical.
- Retract the blanket `unsafeFlags` ban; those flags pass the controlled enabled-test experiment.
- Earlier ADRs are marked superseded, not silently rewritten.
- White paper receives only the corrected general testing principle, no probe ledger.
- Owning-suite migration can now proceed under roadmap 0003. Entry 0005 closes blocker 2.
