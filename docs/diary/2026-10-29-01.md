# 2026-10-29 (1) — Consolidation from ask: the page, the appearance, the scroll rules

Moved from ask (its roadmaps 0074, 0108, 0125) into the kit, each with deterministic tests: `TerminalPage` (WCAG maths, tints, secondary
text) in Codecs, `PageFollower` and `SystemAppearance` in Input, `ScrollPosition` in Text. See roadmap 0021 for the table.

Learned: `Notification.Name` cannot appear in a public declaration of a module that imports Foundation internally, so the notification's name
is a string constant; a real `DistributedNotificationCenter` post does reach an observer in the test process (3 of 3), so the watcher is tested for
real and not through a seam. The re-ask delays take an injectable clock, tested under `TestClock` with a rendezvous on `waitForSleepers`, no
sleeping.

Records: a status paragraph on 0016 to 0020 against what ask uses today (0019's "ask does not use any of it" was stale), and new entries 0022
(Markdown renderer), 0023 (row windows, from ask's 0088 measurement), 0024 (Linux), 0025 (event-driven).

## Row windows, step 1 (roadmap 0023)

`WindowedLayout` beside `LayoutCache`: heights for every item, lines near the window. ask's transcript uses it, and drops the second copy
of every item's hard lines it held for the highlight (the highlight only resolves which items a selection names). A copy of the owner's
12 MB session: 61.2 to 54.9 MiB resident, a new width 300 to 240 ms, frames unchanged. Measured as RSS against a baseline binary run
interleaved, because the machine's load moved the absolute figures by a factor of two between runs.

## Row windows, step 2 (roadmap 0023, done)

`WindowedLayout` now lays out from the end on demand: opening the 12 MB session takes 230 ms instead of 440, a resize 15 ms instead of 231,
resident size 52.7 MiB instead of 60.9. Two things the first profile found: the frame walked every item below the window and touched a
dictionary for each, which unspecialised across the module boundary cost generic metadata per call (now binary search and the held items
only); and ask counted a folded block's output lines by splitting the whole output. A Page Up still costs 1.2 ms more, the layout of what it
reaches. The earlier Page Up figures were void: ask did not scroll on Page Up before a mouse event, fixed in ask.
